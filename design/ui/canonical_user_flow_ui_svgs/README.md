# Canonical UI Flow — 최종 권장 화면 31개

이 폴더는 지금까지 만든 화면 중 **사용자 플로우마다 하나의 최선안만** 남긴 구현 기준 패키지입니다.

|---|---:|---|
| 01_AUTH | 6 | 소셜 로그인, 약관, 프로필, 완료, 계정 충돌, 인증 오류 |

총 모바일 화면은 31개이며, `00_CANONICAL_USER_FLOW.svg`는 전체 흐름도입니다.

## 선택 기준

1. **가입 마찰 최소화**: 이 앱의 소비자 서비스 성격에 맞춰 소셜 로그인 전용안을 최종안으로 선택했습니다.
2. **저장됨에서 바로 지도 이동**: 카테고리/내 보관함 탭 하단의 `지도에서 보기`를 사용합니다. 중간의 ‘어떤 기준으로 볼까요?’ 화면은 제거했습니다.
3. **추출 결과 검토 강화**: 단순 체크리스트였던 초기 추출 결과 대신 원본 확인·중복 상태·저장 수량을 보여주는 검토 화면을 선택했습니다.
4. **코스 생성은 단계형**: 코스 정보 → 저장 장소 → 혼자/함께 → 초대/취향 → AI 추천 → 완료 순서로 통일했습니다.
5. **중복 제거**: 같은 목적의 지도 화면, 초기 저장됨 화면, 별도 파티 목록, 전체 저장 장소 리스트, 실험용 컴포넌트는 제외했습니다.

## 제외한 주요 화면

- 소셜 + 이메일 로그인 전체안: 기능은 많지만 초기 진입 부담이 커서 최종안에서는 제외
- 지도 보기 기준 선택 바텀시트: 현재 탭의 맥락으로 충분해 한 단계 단축
- 초기 `추출 결과`: 개선된 `추출 결과 검토`로 교체
- 별도 `모임/파티 코스` 목록: 코스 목록 화면에서 함께 보여주므로 통합
- 전체 `저장된 장소 리스트`: 카테고리/보관함 탐색과 중복되어 제외
