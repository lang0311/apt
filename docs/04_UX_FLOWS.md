# 04. UX 흐름

> 전체 흐름도 이미지: `canonical_user_flow_ui_svgs/PREVIEWS/canonical_user_flow.jpg` (구현 전에 먼저 확인)
> 아래는 그 흐름도 + 이번에 확정된 변경(공유 진입, 이메일 틀, 코스 루프, 취향 설정)을 반영한 것이다.

## 0. 전체 지도

```
[앱 시작]
   ├─ 미로그인 → A. 인증
   └─ 로그인 → 홈 ─┬─ 코스 탭   → D. 코스 만들기 / 관리
                   ├─ 저장됨 탭 → C. 저장 라이브러리 → 장소 상세
                   ├─ 추출 탭   → B. 추출 (링크 입력 폴백)
                   └─ 마이 탭   → F. 취향 · 설정

[외부] 인스타그램 릴스 → 공유 → 우리 앱 ──→ B. 추출 (주 경로)
[외부] 초대 링크 ───────────────────────→ E. 파티 초대 수락
```

하단 탭 5개(홈·코스·저장됨·추출·마이)는 **현재 라우트 기준**으로 활성 표시. 탭바가 숨겨지는 화면: 인증 전체, 보관함 선택 시트, 새 보관함 모달, 코스 만들기 위저드 및 장소 선택/추가, 초대 수락, 지도 풀스크린.

## A. 인증

```
소셜 로그인 ─(신규)→ 약관 동의 → 프로필 설정 ─(취향 설정하기 ›)→ [취향 설정] → 프로필 설정 → 가입 완료 → 홈
    │          └(기존)→ 홈
    ├─ 계정 충돌 (#5)  → 기존 계정과 연결 / 다른 계정
    ├─ 소셜 인증 오류 (#6) → 다시 로그인 / 고객센터
    └─ [flag] 이메일로 로그인 (#7) ─ 실패 → 인라인 오류 (#8)
                                  └ 비밀번호 찾기 / 이메일 가입 (TODO 스텁)
```
- 이메일 진입 링크는 **feature flag가 켜졌을 때만** 소셜 로그인 화면 하단에 노출.
- 이메일 로그인은 틀만: 폼 검증(형식/빈 값), 오류 표시, 로딩 상태까지.
- 공유로 들어왔는데 로그인 전이면 **URL 보류 후 로그인 완료 시 재개** (02 문서 §5.3).

## B. 장소 추출 · 저장 (핵심)

### 주 경로 — 인스타 릴스 "공유"
```
릴스 → 공유 → (시스템 공유 시트) → 우리 앱
   → URL 검증 → [추출 진행 중] → 추출 결과 검토 (#11) → 보관함 선택 (#12) → 저장 완료
                                    └ 실패/없음/비공개 → 오류 상태 → 재시도 or 링크 직접 입력
```
- 링크 입력 화면(#10)을 **거치지 않고** 결과 검토로 바로 진입하며 분석은 자동 시작.
- 추출 진행/오류 상태는 디자인에 없음 → 임시 컴포넌트로 구현 후 필요 시 디자인 요청.

### 보조 경로 — 앱 안에서 링크 입력
```
추출 탭 (#10) → URL 붙여넣기/클립보드 → 장소 추출하기 → (이후 동일)
```
- SNS 주소를 이미 알고 있을 때 사용. 클립보드에 인스타 URL이 있으면 붙여넣기 제안.

### 결과 검토(#11) 규칙
- 장소 카드 선택(복수), **이미 저장됨**은 선택 불가 표시
- `원본 게시물 확인하기 ›`로 출처 확인
- CTA: `선택한 N곳 저장하기` → 보관함 선택 시트(복수 선택, 기본은 "전체 저장 장소", 새 보관함 만들기 가능)
- 저장 후 이동: 저장됨 또는 장소 상세 (SCREEN_FLOW: `saved_or_place_detail`)

## C. 저장 라이브러리

```
저장됨 [카테고리 | 내 보관함]
  ├ 카테고리 → 카테고리 지도(#18) ┐
  └ 내 보관함 → 새 보관함(#15) / 빈 보관함(#16) / 보관함 상세(#17) → 보관함 지도(#19) ┤
                                                                         └→ 장소 상세 (#20)
장소 상세 ─ 보관함 변경 (#12 시트) / 코스 만들기 (장소 사전 선택)
빈 보관함 ─ 저장한 장소에서 추가 / SNS 링크에서 새 장소 추출 (→ B)
```
- `지도에서 보기`는 **현재 탭 맥락**으로 바로 지도 진입 (중간 선택 화면 없음).
- 한 장소는 여러 보관함에 속할 수 있다.

## D. 코스 만들기 — 루프 포함

```
코스 목록/빈 상태 ──(+ / 첫 코스 만들기)──┐
 장소 상세 `코스 만들기` ──────────────────┤  (해당 장소 사전 선택)
 보관함 상세 `이 보관함으로 코스 만들기` ──┘  (보관함 장소 일괄 불러오기)
                    ▼
 [1/4 정보]  이름 · 날짜 · 시작 시간 · 분위기
                    ▼
 [2/4 장소]  저장한 장소 선택 (지도 + 시트, 선택 순서 번호)
                    ▼
 [3/4 동행]  혼자 ⇄ 함께 (같은 화면의 토글)
        ├ 혼자 : 나의 취향으로 추천
        └ 함께 : 파티원 초대 (모달 25) · 파티원 취향 요약
        └ (공통) 장소 더 추가하기 (#29) · 순서 드래그
                    ▼
 [4/4 AI 추천]  추천 동선 검토  ◀─────────────┐
        ├ 장소 수정 (교체 · 삭제 · 순서 · 추가) ─┘  → 「다른 추천」 = AI 재추천 (반복 가능)
        └ 「이 코스로 완성하기」
                    ▼
 [완료 29] → 코스 보기 → [코스 상세·관리 30]
                              ├ 순서 편집 / 장소 추가 / 다른 추천 받기  ──→ (루프 재진입)
                              └ 코스 공유
```

### 루프 규칙 (확정: "장소 수정 → AI 재추천"은 반복 가능)
1. 루프는 **4/4 단계 안에서 반복**된다. 진행 바는 4/4로 유지, 새 단계를 만들지 않는다.
2. 사용자가 고른 장소(`USER`)와 AI가 넣은 장소(`AI`)를 **항상 시각적으로 구분**한다 (주황 ✦ + 이유 라벨).
3. 수정 후 "다른 추천"을 누르면 **현재 코스 상태를 기준으로** 다시 추천받는다. 사용자가 방금 뺀/바꾼 추천은 다시 나오지 않아야 자연스럽다 → 서버 지원 여부 확인(06 문서).
4. 재추천 중에는 이전 결과를 유지한 채 로딩 표시(깜빡임/빈 화면 방지). 실패하면 이전 결과로 복구 + 재시도.
5. 4/4에서 뒤로 가면 3/4로 가고 **입력은 유지**. 3/4에서 장소가 바뀌면 이전 AI 결과는 무효 안내.
6. 완성 후(#32)에도 같은 루프를 재진입할 수 있다 (수정 내용은 코스에 즉시 반영/저장).
7. 재추천 횟수 제한이 있다면(비용/쿼터) 서버 응답에 따라 안내.

### 파티 코스 (함께 갈게요)
```
3/4 함께 → 파티원 추가 → 초대 모달(카카오톡 초대 / 링크 복사)
   → 파티원이 링크 열기 → [초대 수락 26] → 코스 참여 (내 저장 장소·취향 반영 체크)
   → 파티원 취향 종합(서버) → 4/4 AI 추천 (취향 반영 비율 표시)
```
- 초대 수락 화면에는 **참여 시 공개되는 정보**(취향 키워드, 코스에 선택한 장소)를 명시.
- 초대 상태 예외(만료·이미 참여·인원 초과)는 디자인에 없음 → 간단한 에러 상태로 처리.

## E. 파티 초대 수락 (파티원 관점)

```
초대 링크 → (미로그인이면 인증 후 복귀) → 초대 수락 (#28)
   ├ 코스에 참여하기 → 코스 목록의 "모임/파티 코스" 탭에 표시
   └ 이번에는 참여하지 않기
```
- 미로그인 상태에서 링크를 열면 초대 토큰을 보류했다가 인증 후 복귀(공유 URL 보류와 같은 패턴).
- 취향이 비어 있으면 참여 후 **취향 설정 안내**(선택)를 고려.

## F. 취향 설정 · 마이

```
진입점 1: 가입 중 프로필 설정 → "추천에 사용할 기본 취향 · 설정하기 ›"
진입점 2: 마이 → 취향 설정 카드
(진입점 3 제안: 파티 참여 시 취향이 비어 있으면 안내)
   → 취향 설정 (#34): 칩 선택 → 저장 → 이전 화면 복귀
```
- 가입 중 진입 시에는 저장 후 **프로필 설정으로 복귀**, 마이 진입 시 마이로 복귀 + 토스트.
- 취향 칩의 그룹/항목은 **서버의 키워드 체계를 따른다** (화면의 항목은 예시).
- "저장한 장소로 취향 자동 분석" 스위치는 암묵적 취향 사용에 대한 **사용자 동의 표시**. 서버가 지원하지 않으면 이 카드는 제거.
