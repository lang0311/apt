## 3. 미해결 항목

### 디자인이 아직 없는 것
- [ ] **추출 진행 중 / 실패 / 비공개 게시물 / 장소 없음** 상태 화면 (공유 진입에서 가장 자주 마주칠 화면 → 우선순위 높음)
- [ ] **공유로 들어왔을 때** 첫 진입 연출(결과 화면 내 로딩) 확정
- [ ] 이메일 가입/비밀번호 찾기 (flag on 시점에 필요)
- [ ] 마이 하위: 내 활동 · 알림 · 개인정보 설정 · 도움말
- [ ] 초대 수락 예외(만료·이미 참여·인원 초과)
- [ ] 보관함 ⋯ 메뉴(이름 변경·삭제), 코스 ⋯ 메뉴(삭제·나가기 등)
- [ ] 코스 공유 화면/시트
- [ ] 추천 결과 0건 / 재추천 실패

### 정책/기획 확인
- [ ] 취향 최소/최대 선택 개수, 0개 저장 허용 여부
- [ ] 파티원에게 공개되는 정보의 최종 범위
- [ ] 코스 편집 권한(소유자/참여자), 파티 코스 동시 수정 처리
- [ ] 재추천 횟수 제한 여부
- [ ] 서비스 지역 범위(국내 한정 여부 — 네이버 지도 영향)
