## 3. 미해결 항목

### 디자인이 아직 없는 것
- [ ] **추출 진행 중 / 실패 / 비공개 게시물 / 장소 없음** 상태 화면 (공유 진입에서 가장 자주 마주칠 화면 → 우선순위 높음)
- [ ] **공유로 들어왔을 때** 첫 진입 연출(결과 화면 내 로딩) 확정
- [ ] 이메일 가입/비밀번호 찾기 (flag on 시점에 필요)
- [ ] 마이 하위: 내 활동 · 알림 · 개인정보 설정 · 도움말
- [ ] 초대 수락 예외(만료·이미 참여·인원 초과)
- [ ] 보관함 ⋯ 메뉴(이름 변경·삭제), 코스 ⋯ 메뉴(삭제·나가기 등)
- [ ] 코스 공유 화면/시트
- [ ] 추천 결과 0건 / 재추천 실패

### 정책/기획 확인
- [ ] 취향 최소/최대 선택 개수, 0개 저장 허용 여부
- [ ] 파티원에게 공개되는 정보의 최종 범위
- [ ] 코스 편집 권한(소유자/참여자), 파티 코스 동시 수정 처리
- [ ] 재추천 횟수 제한 여부
- [ ] 서비스 지역 범위(국내 한정 여부 — 네이버 지도 영향)
- [ ] 이미 저장된 장소를 다른 보관함에 추가하는 UX (11의 "이미 저장됨" 처리와 연계)

### 기술 확인
- [ ] 인스타그램 공유 메뉴에서 시스템 공유 시트 → 우리 앱 노출 경로를 **실기기(iOS/Android)에서 검증**
- [ ] iOS Share Extension + App Group 구성 가능 여부 (개발자 계정/프로비저닝)
- [ ] 네이버 지도 Flutter SDK 버전/키 발급/약관
- [ ] 경로 polyline/이동시간의 제공 주체 (서버 vs 앱 직접)
- [ ] 소셜 SDK 키(카카오/Google/Apple), Apple 로그인 심사 요건
- [ ] 기존 Flutter 레포 존재 여부 → 있으면 구조/상태관리/라우터 확인
