## 1. AUTH

### 1 소셜 로그인 · `/login`
- UI: 로고, 카피 "가고 싶은 곳을, 하나의 코스로.", 카카오(노랑)/Google(흰)/Apple(검정) 버튼, "처음 로그인하면 자동으로 회원가입됩니다.", 약관·개인정보 고지
- 동작: 성공 → 신규=약관 / 기존=홈. 취소·실패 → 6. 이메일 중복 → 5
- **flag on일 때만** 하단에 `이메일로 로그인` 텍스트 링크 노출 → 7
- 상태: 버튼 로딩, 플랫폼 제한(Apple은 iOS 정책상 소셜 제공 시 필수 — 심사 요건 확인)

### 2 약관 동의 · `/signup/terms`
- UI: 전체 동의 / 만 14세 이상(필수) / 서비스 이용약관(필수) / 개인정보 수집·이용(필수) / 맞춤 장소 추천 정보 수신(선택), `동의하고 계속하기`
- 동작: 필수 3개 충족 시 버튼 활성. 각 행 `›` = 약관 본문
- 데이터: 약관 버전/URL, 동의 이력 전송

### 3 프로필 설정 · `/signup/profile`
- UI: 프로필 사진(변경), 닉네임 입력, "추천에 사용할 기본 취향 · 설정하기 ›", `가입 완료하기`
- 동작: `설정하기 ›` → 34(취향 설정, 온보딩 모드) → 복귀. 취향은 나중에 설정 가능
- 상태: 닉네임 유효성/중복(규칙은 서버), 이미지 업로드 중/실패

### 4 가입 완료 · `/signup/done`
- UI: 체크, "가입이 완료됐어요", `시작하기` → 홈. 보류된 공유 URL이 있으면 홈에서 추출 재개

### 5 기존 계정 충돌 · `/login/conflict`
- UI: 마스킹 이메일, `기존 계정과 연결하기` / `다른 계정으로 로그인`

### 6 소셜 인증 오류 · `/login/error`
- UI: 오류 안내 + 해결 방법, `다시 로그인하기` / `고객센터 문의`

### 7★ 이메일 로그인 (틀) · `/login/email`  — `ui_additions/01_AUTH/07_email_login.svg`
- UI: 뒤로, 제목 "이메일로 로그인", 이메일/비밀번호 필드(아이콘, 비밀번호 보기 토글), `비밀번호 찾기`, `로그인`, "아직 계정이 없나요? 이메일로 가입하기"
- **틀만 구현**: 폼 검증(이메일 형식/빈 값), 버튼 활성/로딩, 오류 표시. 실제 인증은 stub/Mock. `비밀번호 찾기`, `이메일로 가입하기`는 TODO 라우트.
- flag off 시 진입 불가.

### 8★ 이메일 로그인 오류 · 7의 상태  — `ui_additions/01_AUTH/08_email_login_error.svg`
- UI: 두 필드 빨강 테두리 + 아이콘 + "이메일 또는 비밀번호가 올바르지 않아요." (보안상 어느 쪽이 틀렸는지 구분하지 않음) + `비밀번호 찾기` 유지
- 별도 화면이 아니라 **같은 화면의 오류 상태**. 입력 수정 시 오류 해제.
- 그 외 오류(네트워크 등)는 스낵바.

## 2. HOME

### 9 홈 대시보드 · `/home`
- UI: 인사 "오늘은 **어디로** 떠날까요?", 알림/위치 아이콘, 통계 3타일(저장된 장소·진행 중인 코스·최근 추출 · 각 탭으로 이동), **최근 추출한 장소**(출처 URL·추출 시점·키워드·`저장됨`/`저장하기`), **지금 뜨는 장소**(가로 카드, "지금 인기"), **내 코스 바로가기**(`이어보기`)

- 상태: 섹션별 빈 상태(예: 최근 추출 없음 → 추출 유도)

## 3. EXTRACT & SAVE

### 10 링크 입력 (폴백) · `/extract`
- UI: 안내 카드, URL 필드, `클립보드에서 붙여넣기`, 이용 방법 1·2·3, "공개 게시물만 지원해요", `장소 추출하기`
- 위치 선정: **주 경로는 릴스 공유**, 이 화면은 SNS 주소를 아는 경우용. 공유 수신 시 이 화면을 건너뜀.
- 상태: URL 형식 오류, 클립보드 비어 있음, 분석 중(진행 단계), 분석 실패/비공개/장소 없음(★디자인 없음)

### 11 추출 결과 검토 · `/extract/result`
- UI: "N곳 발견", 장소 카드(사진·주소·카테고리·키워드, 선택 표시), 이미 저장됨 상태, `모두 선택`, `원본 게시물 확인하기 ›`, `선택한 N곳 저장하기`
- 공유 진입 시: 분석 로딩을 이 화면에서 보여주고 완료되면 목록 표시
- 상태: 0곳 발견, 전부 이미 저장됨, 일부 실패

### 12 보관함 선택 · 바텀시트
- UI: 상단 장소 요약, 보관함 체크 리스트(**복수 선택**): 전체 저장 장소(기본) / 내 보관함들(장소 수) / `새 보관함 만들기`, `N개 보관함에 저장하기`
- 동작: 저장 후 저장됨 또는 장소 상세. `새 보관함 만들기` → 15
